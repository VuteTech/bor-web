# Policy-type marks

Flat single-colour SVG marks for the "Supported policies" section on the
homepage. They are the same artwork the Bor web console uses for its policy
types (`server/web/frontend/src/icons/policyTypes/` and
`@patternfly/react-icons`), so the website and the console stay visually in
step. Each file is `fill="currentColor"` and is inlined by
`layouts/partials/section4.html`, so colour comes from CSS.
